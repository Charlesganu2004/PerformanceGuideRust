Install

Install it in one paste.

No account and no administrator rights. The installer downloads one program file, checks it against the published checksums and puts it in a folder of your own account. Nothing else is installed.

Run it in PowerShell. No administrator rights.

Run it in a terminal. No root.

irm https://github.com/Charlesganu2004/PerformanceGuideRust/releases/latest/download/install.ps1 | iex
curl -fsSL https://github.com/Charlesganu2004/PerformanceGuideRust/releases/latest/download/install.sh | sh

Then

Three commands to start.

Run them inside the repository you want to search.

pgr refresh

Prepare the repository you are in. Run it once, and again after the code changes.

pgr ask about:SomeFunction "find:where tokens expire"

Ask two questions in one call: where SomeFunction is defined and what calls it (use a name from your code), and which code does a job you can only describe.

pgr help

Every command, with what it prints.

Tell your agent

Four lines for your agent.

Put these in the instructions your agent reads at the start, so it asks pgr before it reads files.

Before reading files to find where something is, run pgr ask. For a name, run pgr ask about:NAME: the definition, the callers and what it calls. For a job you cannot name, run pgr ask "find:what the code does". Open a file only for the lines the answer names.

Checked

What was tested.

Last checked 13 October 2026, before the release moved to this repository. No later run of the installers is recorded.

Ran

  • The Windows installer, on Windows 11, from the public release, followed by a first index build and a query in a new repository.
  • The shell installer, on Ubuntu, from the public release, with the same first index build and query.
  • Installing the wheel with pip, on both of those systems.
  • The build workflow installed and ran the Windows, Linux x86-64 and macOS Apple-silicon builds.

Not run

  • The Linux ARM64 and the macOS Intel builds were cross-compiled and checked, not run.
  • The Linux builds need the GNU C library, so Alpine (musl) is not covered yet.
